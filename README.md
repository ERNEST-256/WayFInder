# WayFinder

WayFinder is a travel planning service. This repository separates the web client, API, database assets, AI prompts, and deployment configuration.

## Quick start

1. Copy `.env.example` to `.env` and set local values.
2. Run `npm install --prefix backend`.
3. Run `npm run dev` and open `http://localhost:4000/health`.

The frontend currently provides a dependency-free product shell in `frontend/`.
